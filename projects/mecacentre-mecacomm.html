CTO, Architecte DMS sur mesure

2025 - Présent

Statut
En Production
Type
DMS + Agent IA
Secteur
Automobile
🚗 📱

Vue d'ensemble

Conception et développement d'un système de gestion commerciale (DMS) sur mesure pour le secteur automobile, intégrant un agent conversationnel intelligent "TakTak" qui automatise les interactions clients via WhatsApp.

Ce projet représente une innovation majeure dans la digitalisation du secteur automobile en Tunisie, combinant gestion commerciale traditionnelle et intelligence artificielle pour offrir une expérience client fluide et automatisée 24/7.

Faits clés

  • Agent IA "TakTak" répond automatiquement aux demandes clients 24/7 via WhatsApp avec support multilingue (FR/AR/EN)
  • Vérification en temps réel des prix et disponibilités depuis SQL Server pour des réponses instantanées et précises
  • Passage de commandes automatisé via conversation WhatsApp, réduisant le temps de traitement de 80%
  • Intégration complète avec système de gestion commerciale existant sans interruption de service
  • Support multilingue (FR/AR/EN) pour l'agent conversationnel avec détection automatique de la langue
  • Architecture microservices ASP.NET + Node.js pour haute disponibilité et scalabilité

Technologies utilisées

ASP.NET Core Node.js SQL Server OpenRouter Qwen AI WhatsApp API Docker CI/CD

Défis techniques

1. Intégration système legacy : L'un des principaux défis était d'intégrer l'agent IA avec un système de gestion commerciale existant sans perturber les opérations quotidiennes. Solution mise en place : architecture microservices avec API RESTful permettant une communication bidirectionnelle sécurisée.

2. Temps de réponse IA : Garantir des réponses quasi-instantanées malgré la complexité des requêtes. Solution : mise en cache intelligente des données fréquemment demandées et optimisation des requêtes SQL Server.

3. Support multilingue : Gérer les conversations en FR/AR/EN avec détection automatique. Solution : fine-tuning du modèle Qwen2.5 avec vocabulaire automobile local et détection de langue par NLP.

Résultats & Impact

Amélioration de l'expérience client : Réduction du temps de réponse moyen de 3 heures à moins de 2 minutes pour les demandes standard.

Augmentation des ventes : +35% de conversion sur les demandes reçues via WhatsApp grâce à la réactivité de l'agent IA.

Optimisation des ressources : Réduction de 60% de la charge de travail du service client sur les tâches répétitives, permettant de se concentrer sur les cas complexes.

Disponibilité 24/7 : Service client automatisé disponible en dehors des heures d'ouverture, captant des opportunités commerciales auparavant perdues.
